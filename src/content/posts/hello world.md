应该从读研开始，我的闲暇时间愈发减少，少有时间写作。不过究其本质，还是感触和体验少了，离开曾经悲剧的内核我竟无从下笔。

其实中途我写《心寻》时，写作的主题已经从情感转为思辨，但其内核还是悲观的。我也试图去写一些振奋人心或者充满激情的话，可我做不到。

我的内心是矛盾的，希望一旦产生，失望便如影随形。貌似，热烈的情感从未给予我善果，取而代之的是混乱和迷茫。于是我把情感隐匿于每一次沉默，每一次远眺和每一次感叹夕阳的壮美之时。

我无法克服这种矛盾，就像史铁生先生写的“太阳他每时每刻既是朝阳也是旭日”，而我给自己找了个不一样的意象——月亮。

我喜欢月亮，因为它光芒却不刺眼，每个人都可以直视却不敢亵渎。我时常感叹，月亮阴晴圆缺还是那个月亮，但人经悲欢离合还是那个人吗？

月亮更像是一种永恒和真理，它始终代表着理智和圆满。清冷的月辉照耀每个人却不属于任何人，它属于生命和宇宙。无论你欣喜还是悲伤，它始终在哪儿，平静地看着你。

言归正传吧，讲讲我为什么要开始写博客？

其实在年初，我心血来潮根据 b 站教程搭了一个博客网站（见首页旧版链接）。也往上贴了一些曾经写的文章，但由于迟迟写不出新的，于是把以前写的一些文章做成合集又贴了几篇，比如薄月纪和心绪三叠。自那以后，便一直停滞了创作。后来我也发现，我其实只是满足于搭网站的成就感，以及类似的我搭建了 obsidian 的创作库，把我曾经写的所有文章都整理在一起。但只要整理好后就难有创作了，只是去欣赏我搭建的系统，却忘了系统最重要的一环——输入和输出。

鉴于我对写作系统的高审美要求（旧版的 UI 实在太老了），毕竟我的 obsidian 足够的美观和简洁。于是我重新注册了一个账号（因为不想去买域名，所以索性新注册了一个 github 账号，将用户名换成了我的笔名归梧遥），选择了新的博客主题打算重新开始。

所以现在的博客网站诞生了，我并非计算机类专业出身，很多代码基础都不懂。因此选择了现在这个开箱即用无需过多修改的 fuwari 主题。整个部署过程按照官方 github 部署教程照猫画虎即可。然后开始写我的第一篇，也就是你正在读的这一篇博客。

我希望这是新的开始，我要重拾写作的习惯，只有写作和文学才能给我一份净土，独属于我的自由王国。

> 不要苛求重逢，不要独钟实现，不要怨甚至不要说……那美丽的位置也许只好在心里，在想像里，在梦里，只好在永远不能完成的你的长诗里……
> 
> ——史铁生《务虚笔记》

后续的计划可能是不定时分享一些自己的感悟吧，也有可能分享一些自己学到的东西，与诸君共勉。
